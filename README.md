## 让跨语言沟通更顺手

[![出海王 · SailKing：在当前输入框，把中文变成另一种语言。](assets/sailking.svg)](https://github.com/sapplex-sz/SailKing)

**出海王输入法**把中文拼音、英文输入和本机翻译放在一起。写好原文、预览译文，确认后再上屏，也可以在独立工作台处理长段文字。

[查看项目与安装说明 →](https://github.com/sapplex-sz/SailKing) · [版本记录](https://github.com/sapplex-sz/SailKing/releases)

<sub>Mac 版面向 macOS 26+ / Apple Silicon；Windows 版处于预览阶段。</sub>

## 给创作者少一点重复劳动

[![长图文发布助手：整理一次图文，让发布少一点重复劳动。](assets/publish.svg)](https://github.com/sapplex-sz/chang-tuwen-publisher)

**长图文发布助手**把文章和图片整理成可离线打开的 HTML，支持实时预览、图文复制和分步发布。内容在本地处理，整理好后由你发布到目标平台。

[查看工具与使用方法 →](https://github.com/sapplex-sz/chang-tuwen-publisher)

也在探索声音创作：**[云途觉晓多人语音工作室](https://github.com/sapplex-sz/YuntuJuexiao-MultiVoice-Studio)**，将带角色标记的脚本转换为多人语音。基于 OpenMOSS/MOSS-TTSD 的社区改造，加入中文工作流、本地转写与 V100 适配。
