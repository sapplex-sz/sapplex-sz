## 跨语言沟通 · Communicate across languages

[![出海王 SailKing — 在当前输入框翻译 / Translate in the field you're typing in](assets/sailking.svg)](https://github.com/sapplex-sz/SailKing)

**出海王输入法**把中文拼音、英文输入和本机翻译放在一起。写好原文、预览译文，确认后再上屏，也可以在独立工作台处理长段文字。

**SailKing** brings Chinese Pinyin, direct English input, and on-device translation into one input method. Write your text, preview the translation, and confirm before inserting it into the current text field. A standalone workspace also handles longer passages.

[项目与安装说明 / Project & installation →](https://github.com/sapplex-sz/SailKing) · [版本记录 / Releases](https://github.com/sapplex-sz/SailKing/releases)

<sub>Mac 版面向 macOS 26+ / Apple Silicon；Windows 版处于预览阶段。<br>Mac: macOS 26+ on Apple Silicon. The Windows version is a preview.</sub>

## 创作少一点重复 · Less repetition for creators

[![长图文发布助手 Article Publishing Helper — 整理一次图文 / Prepare your article once](assets/publish.svg)](https://github.com/sapplex-sz/chang-tuwen-publisher)

**长图文发布助手**把文章和图片整理成可离线打开的 HTML，支持实时预览、图文复制和分步发布。内容在本地处理，整理好后由你发布到目标平台。

**Article Publishing Helper** turns text and images into self-contained HTML that you can open offline. It offers live previews, rich-text copying, and step-by-step copying for different publishing platforms. Content is processed locally; you review and publish it yourself.

[工具与使用方法 / Project & usage guide →](https://github.com/sapplex-sz/chang-tuwen-publisher)

**[云途觉晓多人语音工作室 / Yuntu Juexiao MultiVoice Studio](https://github.com/sapplex-sz/YuntuJuexiao-MultiVoice-Studio)** 将带角色标记的脚本转换为多人语音。基于 OpenMOSS/MOSS-TTSD 的社区改造，加入中文工作流、本地转写与 V100 适配。

**MultiVoice Studio** converts scripts with speaker labels into multi-speaker audio. It is a community adaptation of OpenMOSS/MOSS-TTSD, with Chinese-language workflows, local transcription, and Tesla V100 compatibility.
